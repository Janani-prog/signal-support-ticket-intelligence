Customers are primarily reporting issues with the newly deployed express checkout flow, specifically concerning payment method retention.

Based on 42 analyzed tickets from the past 7 days, there is a recurring theme where returning users attempt to use saved credit cards during the express checkout process, but receive an "Invalid Token" error [1][2]. This appears to be localized to the iOS mobile application, as web users have not reported similar failures in the same volume [4].

A secondary, albeit smaller, cluster of feedback mentions confusion regarding the application of promo codes. Users state the input field is hidden behind an accordion menu that defaults to closed, leading to abandoned carts when they cannot easily apply discounts [3].
